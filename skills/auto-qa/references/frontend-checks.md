# Exercise changed controls

Launch the real app or production-like preview with the intended configuration. Record the command and the launch result, including failure. Reuse one safe local session.

Click, tap and type through changed controls. Cover the happy path and applicable close/cancel/back, disabled, repeat and keyboard states. Verify visible results, navigation, persistence and side effects. Check for console errors and failed network requests on the exercised flows.

Capture evidence per flow. Prefer a DOM/accessibility snapshot or concise console/network evidence. Capture screenshots when testing appearance, stacking or OS behavior. Add viewports or themes only when touched.
