# Delegate a bounded slice

Delegate only when parallelism or context isolation justifies the briefing cost. When the host offers model selection, use a fast low-cost tier for mechanical work and the strongest tier for Full-tier design and diagnosis. Otherwise use the configured default.

Give the worker paths to the relevant inputs and request a short status with evidence. Check all feedback against source and receipts. Discard speculative, stale, duplicate and out-of-scope advice.
